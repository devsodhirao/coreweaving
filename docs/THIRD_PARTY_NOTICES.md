# Documentation sources

`data/docs/weave-snapshot-4db7c17b2869.zip` contains 351 Weave documentation
pages published by Weights & Biases / CoreWeave and fetched on October 25, 2026.
The original downloaded Markdown bytes are preserved without edits. The adjacent
`manifest.json` retains every original and canonical URL, retrieval time, byte
count and SHA256. Compression and ZIP metadata do not change the page contents.
Links in answers point back to the original documentation.

Preserve that license and this notice when redistributing the snapshot. Copyright
