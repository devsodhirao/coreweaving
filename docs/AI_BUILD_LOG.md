## What remains important to explain

The agent's four tools and runtime limits, source passages versus search snippets, six exchanges of working context versus persistent review records, and why a verifier pass can still be wrong. New library entries are unreviewed; human approval and dataset promotion are deliberate. Two early records lack newer version identities and stay unknown rather than being backfilled. [Behavior contract](BEHAVIOR_CONTRACT.md) · [Versioning](VERSIONING.md)

Weave supplies the inspectable conversation/evaluation/feedback record; the agent and judge use Anthropic, while the online Signal uses CoreWeave Serverless Inference. We did not train a model or host this app on CoreWeave GPUs. The independent evaluation exposed a failure, and a live Signal routed one instance for review; neither guarantees correctness.

The completed local suite checks control flow and boundaries. The live navigation/follow-up check confirms two completed turns, not broad answer-quality improvement: the follow-up showed excessive qualification when composing documented context-manager and attribute APIs. Backend readback confirms corrected usage/cost, verifier parent links, SDK identities and synthetic credential masking. Keep the quality limitation visible.
