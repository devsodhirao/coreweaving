To evaluate an agent in Weave, trace each agent run as a conversation. Then go through a task dataset, have an LLM judge score each run's transcript against that task's success criteria, and record everything with weave.EvaluationLogger [S1, S2]. You score a trajectory rather than string-matching one output, because an agent works across several turns and tool calls [S1]. Prerequisites: a CoreWeave Forge account, Python 3.10+, pip install weave anthropic, and ANTHROPIC_API_KEY set. The tutorial uses Anthropic, including for the judge [S3]. Steps Initialize and trace. Call weave.init("[YOUR-TEAM]/[YOUR-PROJECT]"). If you're instrumenting a bare provider SDK yourself, set implicitly_patch_integrations to False so spans aren't duplicated. Wrap each run in start_conversation(...) with turns, LLM calls and tool calls nested inside. Framework integrations (Claude Agent SDK, OpenAI Agents) emit these spans automatically if you leave patching on [S4]. Define the dataset. Use a list of tasks, each with a user_request and success_criteria [S2]. Write the judge. Write a plain function that prompts a judge model with the request, the criteria and the transcript, then returns {"passed": bool, "reason": str}. Weave doesn't require a particular scorer shape [S2]. Run and log. Run the agent inside log_prediction(...) so the traced conversation links to that eval row [S2]. run_agent_turn, new_id and the judge are your own code. Full versions are in the tutorial notebook [S4]. Review. Open the eval link and go to the Evals tab. The Call tab shows a passed column for each task, and View spans opens the linked traces on the Agents page [S2]. Compare versions. Re-run the evaluation with a new model label (for example "v2") and compare the two runs on your scores, latency and cost [S5].

ev = weave.EvaluationLogger(name="support-agent-eval", model="v1", dataset="support-refund-tasks")

for task in tasks:
    with ev.log_prediction(inputs=task) as pred:

        pred.output = reply
