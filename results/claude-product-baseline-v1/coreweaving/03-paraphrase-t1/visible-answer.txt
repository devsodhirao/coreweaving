Pass postprocess_inputs and postprocess_output to the @weave.op decorator. The docs say this changes the data Weave logs "without modifying the original function," for example to hide sensitive data [S1]. Your function body stays as it is.

postprocess_inputs receives a dict of argument names to argument values. It returns a dict of the inputs you want logged [S1].
postprocess_output receives whatever the function would normally return. It returns the version you want logged [S1].
