Pass two postprocessing hooks, postprocess_inputs and postprocess_output, to the @weave.op decorator. Weave changes the data it logs, and your function body stays exactly as it is. The docs give hiding sensitive data as an example use [S1].

postprocess_inputs receives a dict that maps each argument name to its value. It returns a new dict, and that dict is what gets logged [S1]. Use it to drop or mask the password argument.
postprocess_output receives whatever your function returns and gives back a transformed version for the trace. For example, it can return a copy of your object with private fields replaced by "REDACTED" [S1].
Your function still gets the real password, as shown in the example where func uses hide_me to build its result [S1].

Things to keep in mind:

This only works in Python. The docs say it isn't available in TypeScript yet [S1].
I'm assuming the function returns the real object to whoever calls it, since the output hook is described as changing logged data. The docs don't say this outright.
