Use the agents workflow from the "Evaluate your AI agent with Weave" tutorial. You define a set of tasks as your dataset and write an LLM-judge scorer function. Then you loop over the tasks with weave.EvaluationLogger, run the agent on each task, and log the judge's score [S1].

Define the dataset. In the tutorial it is a plain list of task dicts. Each has a task_id, a user_request, and a success_criteria [S1].

Write the LLM judge. The scorer is a plain function, and Weave doesn't prescribe its shape. The tutorial's judge_task_completion(task, transcript) prompts a judge model with the request, the success criteria, and the agent's transcript. It asks for a JSON object and returns {"passed": bool, "reason": str} [S1]. The judge rewards the correct outcome, not a polite reply [S1].

Run the evaluation loop. Create an EvaluationLogger with name, model and dataset labels. For each task, run the agent inside ev.log_prediction(inputs=task), so the traced conversation links to the eval row. Set pred.output, call pred.log_score("task_completion", judge_task_completion(...)), and finish with ev.log_summary() [S1]. The code below is adapted from the tutorial.

ev = weave.EvaluationLogger(name="support-agent-eval", model="v1", dataset="support-refund-tasks")

for task in tasks:
    with ev.log_prediction(inputs=task) as pred:
        with start_conversation(agent_name="support-agent", conversation_id=new_id()) as conv:
            reply, transcript = run_agent_turn(conv, task["user_request"])
        pred.output = reply
        pred.log_score("task_completion", judge_task_completion(task, transcript))

ev.log_summary()

start_conversation, new_id and run_agent_turn are helpers defined elsewhere in the tutorial. I did not run this snippet.

View results. Open the evaluation link and go to the Evals tab. The Call tab shows each task with the judge's passed verdict [S1].

Compare versions. After changing the agent, re-run with a different model label, such as "v2". Then use Weave's compare evaluations feature to see whether the change improved or regressed the logged scores [S2].
