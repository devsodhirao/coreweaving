Pass postprocess_inputs and postprocess_output to the @weave.op decorator. They change what Weave logs, and the docs describe this as a way to hide sensitive data without modifying the original function [S1].

postprocess_inputs receives a dict of argument names to argument values. It returns a dict with the transformed inputs [S1].
postprocess_output receives the value the function would normally return. It returns the transformed output [S1].

In the docs' example, the input hook drops the hide_me argument from the logged inputs. The output hook returns a new CustomObject with secret_password="REDACTED" [S1].

In this example, func still receives the real hide_me value and builds its normal result. The hooks only transform what is recorded. For your case, change hide_me to your password parameter name, or replace its value with "REDACTED" instead of dropping it.

Caveats: this page says the TypeScript SDK doesn't support the feature yet [S1]. I didn't read the other pages that mention these hooks, so I can't say more about how they apply to integrations.
