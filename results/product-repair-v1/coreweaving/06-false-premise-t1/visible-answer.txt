I can't give you an exact call for weave.enable_hallucination_free_mode(). I found no such function in the Weave documentation I searched, so I won't invent a signature. The docs also don't describe any Weave feature that guarantees an agent never hallucinates.

What the docs do support is detecting hallucinations and reacting to them:

Detect with a built-in scorer. HallucinationFreeScorer checks whether your AI system's output includes hallucinations based on the input data. Its score method expects an input column named context, and you can remap it with column_map [S1]. The scorer returns a has_hallucination result, and the docs example reports its counts in an evaluation [S1].
from weave.scorers import HallucinationFreeScorer

scorer = HallucinationFreeScorer()

Run it in an evaluation. Pass the scorer in weave.Evaluation(dataset=..., scorers=[hallucination_scorer]) and call evaluation.evaluate(model) [S1].

Act on scores in real time. Weave guardrails use inline Scorers to assess a user's input or an LLM's output and adjust the LLM's responses [S2]. Guardrails require code changes because they affect your application's control flow [S2]. If you only want to score traffic passively, the docs point to monitors instead [S2].

A scorer is a check that produces a result. It measures hallucination and can drive a guardrail, but the passages I read don't say it prevents hallucination. I didn't read the guardrail example sections, so I can't show a hallucination-specific guardrail. The docs' guardrail examples are described as using a built-in moderation scorer and a custom scorer [S2].
