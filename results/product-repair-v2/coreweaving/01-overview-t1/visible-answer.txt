Weave's tracing is built on Ops, Calls, Traces, and Threads [S4]. [S4]
For agents, the Agents view gives a turn-by-turn record of conversations, with token usage, tool invocations, and execution spans [S2]. [S2]
An Evaluation object defines test examples (a dataset or list) and one or more scoring functions. You run it against a Model or custom function, and each .evaluate() call is an evaluation run [S3]. [S3]
The aim is to measure behavior on repeatable test cases, compare changes over time, and spot regressions [S3]. [S3]
