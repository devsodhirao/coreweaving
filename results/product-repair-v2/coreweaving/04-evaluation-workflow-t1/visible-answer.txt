In Weave's agent evaluation tutorial, you define a dataset of tasks, write an LLM-judge function, loop over the tasks with weave.EvaluationLogger, and log the judge's result as a score [S1].

1. Define the dataset. This is a list of task dicts. Each has a task_id, a user_request, and success_criteria that the judge will check against [S1].

2. Write the LLM judge. The scorer is a plain function, and Weave doesn't prescribe its shape [S1]. In the tutorial, judge_task_completion(task, transcript) does the following [S1]:

It builds a prompt containing the user request, the success criteria, and the agent's transcript.
It asks a judge model to reply with only JSON, {"passed": <bool>, "reason": "<one sentence>"}.
It parses that reply with json.loads and returns it.

3. Run the evaluation and supply the dataset. The tasks are not passed to an Evaluation object here. You loop over them yourself and record each one with EvaluationLogger. The dataset is referenced by name when you create the logger [S1]:

ev = weave.EvaluationLogger(name="support-agent-eval", model="v1", dataset="support-refund-tasks")

for task in tasks:
    with ev.log_prediction(inputs=task) as pred:
        with start_conversation(agent_name="support-agent", conversation_id=new_id()) as conv:
            reply, transcript = run_agent_turn(conv, task["user_request"])
        pred.output = reply
        pred.log_score("task_completion", judge_task_completion(task, transcript))

ev.log_summary()

Some names in this snippet come from the Weave docs and some are placeholders [S3]:

start_conversation is imported from weave.conversation.
new_id() is a placeholder for a unique conversation ID, such as a UUID.
run_agent_turn() is a placeholder for your full agent loop. It returns the final reply and a plain-text transcript of the trajectory for the judge to read. Its full definition is in the accompanying notebook.

Running the agent inside log_prediction(...) links the traced conversation to the eval row [S1].

4. View results. Open the evaluation link and select the Evals tab, then open your run's row. The Call tab shows each task with a passed column holding the judge's verdict. The Evaluation tab has a View spans button that opens the Agents page with the linked traced spans [S1].
