Pass postprocess_inputs and postprocess_output to the @weave.op decorator. Weave then changes the data it logs, and your function body stays as it is [S1].

postprocess_inputs receives a dict of argument names to argument values. It returns the transformed dict that gets recorded [S1].
postprocess_output receives the value your function returns. It returns the transformed value that gets recorded [S1].

The docs example below drops the hide_me argument from the recorded inputs. It also replaces secret_password in the returned object with "REDACTED" according to [S1].

In this example the function still receives the real password in hide_me and uses it. Only the logged inputs and output are altered. To redact a field instead of removing it, set it to a placeholder in the returned dict. I did not run this example, because the offline container has no Weave SDK.

This feature is documented for Python. The docs say it is not yet available in TypeScript [S1].
