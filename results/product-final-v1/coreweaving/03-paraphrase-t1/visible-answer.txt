You can leave the function as it is. Pass two hook functions, postprocess_inputs and postprocess_output, to the @weave.op decorator. They change only the data Weave logs. The docs give hiding sensitive data as an example use [S1].

How it works

Arguments (postprocess_inputs): Weave gives this hook a dict that maps each argument name to its value. The hook returns a changed dict, which is what Weave logs. You can remove a key or replace its value [S1].
Return value (postprocess_output): This hook gets whatever your function returns and gives back a changed version for Weave to record [S1].
Your function still gets the real values: In the docs' example, the function uses the hidden argument to build its result. Only the logged copy is changed [S1].
Python only: The docs say this feature is not available in TypeScript yet [S1].

Example (based on the docs' example [S1], with the password masked instead of removed):

The hooks build new objects instead of editing the ones they receive. That's a precaution I added so your function's actual arguments and return value aren't changed by accident. I haven't run this example.

To drop the password from the record completely, filter it out instead, like the docs do: {k: v for k, v in inputs.items() if k != "password"} [S1].
