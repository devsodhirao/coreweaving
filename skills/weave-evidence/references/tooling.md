# Official tooling to reuse

Source review: **2026-10-28**. These pinned sources establish documented capabilities, not the tools currently exposed by a connection. No MCP installation or account connection was performed for this review.

- [W&B weave-instrument](https://github.com/wandb/skills/blob/4efbb9fd82e8076cbe5d2332167b19f2bba90d85/skills/weave-instrument/SKILL.md): focused instrumentation guidance. [wandb-primary](https://github.com/wandb/skills/blob/4efbb9fd82e8076cbe5d2332167b19f2bba90d85/skills/wandb-primary/SKILL.md): broader SDK operations, including writes. Inspect dependencies before using helpers; installing instructions grants no account access.
- [W&B MCP](https://github.com/wandb/wandb-mcp-server/blob/04fceb2c7a3314b6266c8143372f219a35d23b5e/README.md): hosted endpoint `https://mcp.withwandb.com/mcp`, W&B bearer authentication. Default `models-weave` omits Agents spans. Use an Agents-enabled profile such as `models-weave-agents` for conversation/turn inspection; Dedicated v0.4 rejects these profiles. `WANDB_MCP_ACCESS_MODE=read-only` removes writes. Configuration belongs to the deployment operator; discover actual advertised tools. Local STDIO is available; the plain HTTP development entrypoint is unauthenticated and loopback-only.
- [v0.4.3 availability](https://github.com/wandb/wandb-mcp-server/blob/04fceb2c7a3314b6266c8143372f219a35d23b5e/docs/releases/v0.4.3.md): public-source candidate, hosted deployment under a documented exception, customer/Dedicated channels pending. Do not infer deployment qualification from a source version.
- [Readback guidance](https://github.com/wandb/skills/blob/4efbb9fd82e8076cbe5d2332167b19f2bba90d85/skills/weave-instrument/references/read_back.md): use the Agents surface for OTel conversations; check IDs, pagination, payloads and usage. Empty or failed queries leave verification unresolved.
- [CoreWeave platform skills](https://github.com/coreweave/skills/blob/7681b54acd4522243db1754991c3a1e285762879/README.md): infrastructure deployment/health workflows with their own credentials, permissions and proprietary license. Use for explicit platform work.

This skill complements those tools with evidence and acceptance rules. Continue useful offline inspection when unauthenticated. Before remote reads or writes, establish the authorized project and capability; preserve limits and errors rather than interpreting them as absent application activity.
